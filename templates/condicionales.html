Estructuras Condicionales

Las estructuras condicionales en programación son instrucciones que permiten tomar decisiones dentro de un programa. Su función principal es ejecutar diferentes bloques de código según se cumpla o no una determinada condición lógica (por ejemplo, si una variable tiene cierto valor).

En otras palabras, permiten que el programa reaccione ante distintas situaciones. El tipo más común de estructura condicional es el if, que evalúa una condición y ejecuta un bloque de código solo si esta es verdadera. También existen variantes como if...else (para elegir entre dos opciones) y switch o else if (para múltiples alternativas).

1. if

La estructura más básica. Ejecuta un bloque de código si la condición es verdadera, y opcionalmente otro bloque si es falsa.


if(condicion){
    // codigo si se cumple la condicion
}

2. if else


if (condicion) {
    // código si es verdadero
} else {
    // código si es falso
}

3. else if

Permite evaluar múltiples condiciones en secuencia. Se ejecuta el primer bloque cuya condición sea verdadera.


if (condicion 1) {
    // código si la condicion 1 es verdadera
} else if(condicion 2){
    // código si la condicion 2 es verdadera
}else{
    // codigo si ninguna de las anteriores condicionales no se cumplen
}

4. switch

Útil cuando necesitas comparar una variable contra múltiples valores constantes. Es más legible que múltiples else if cuando se trata de comparaciones de igualdad.


switch (variable) {
case valor1: 
    // código
    break; 
case valor2: 
    // código
    break;
default: 
    // código por defecto 
}
