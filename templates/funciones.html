Funciones

Las estructuras condicionales en programación son instrucciones que permiten tomar decisiones dentro de un programa. Su función principal es ejecutar diferentes bloques de código según se cumpla o no una determinada condición lógica (por ejemplo, si una variable tiene cierto valor).

En otras palabras, permiten que el programa reaccione ante distintas situaciones. El tipo más común de estructura condicional es el if, que evalúa una condición y ejecuta un bloque de código solo si esta es verdadera. También existen variantes como if...else (para elegir entre dos opciones) y switch o else if (para múltiples alternativas).
