# Practica la Sintaxis de Java

Esta sera una aplicion web que ayude a practicar la sintaxis en el lenguaje de programaicon Java.

El objetivo de esta aplicacion es pulir la forma de escribir codigo, no se enseña desde 0 los conceptos.

## Secciones que se practicaran
+ Condicionales
+ Ciclos
+ Arreglos
+ Matrices
+ Funciones
+ Strings

## Mejoras a futuro
+ Ejercicios de tipo codigo completo con error(s) oculto(s).
